# Zoom Roll-Call Bot

Бот для Windows, который сам заходит на пары в Zoom по расписанию, слушает, что говорит преподаватель, и, когда называют вашу фамилию, включает микрофон, проигрывает вашу голосовую запись («Здесь», «Present» и т. п.) и снова выключает микрофон.

Всё работает **бесплатно и локально**: распознавание речи идёт на вашем ПК (faster-whisper), никакие облачные сервисы и платные ключи не нужны.

> Используйте на свой страх и риск и с оглядкой на правила вашего учебного заведения. Автор не несёт ответственности за последствия.

---

## Как это работает

```
расписание ─► открывает ссылку Zoom ─► нажимает Join
                                          │
звук из колонок (loopback) ─► распознавание речи ─► в тексте есть ваша фамилия?
                                                          │ да
Zoom: unmute (Alt+A) ─► случайная запись из answer*.wav ─► виртуальный микрофон (VB-Cable) ─► Zoom: mute (Alt+A)
```

- Ответ даётся **один раз за пару**, после чего прослушивание на этой паре останавливается.
- Недели в расписании могут **чередоваться** (1-я / 2-я неделя).
- Есть окно управления (тёмная тема) с кнопками Start / Stop / Shutdown и ярлык на рабочий стол.

## Состав проекта

| Файл | Что это |
|---|---|
| `zoom_attendance_bot.py` | основной бот и все настройки (в начале файла) |
| `START.pyw` | окно управления: Start / Stop / Shutdown, часы, лог |
| `create_desktop_shortcut.py` | создаёт ярлык «Zoom Bot» на рабочем столе (запустить один раз) |
| `test_join.py` | тестовый запуск без расписания: сразу заходит на одну ссылку |
| `schedule.example.json` | пример расписания (скопируйте в `schedule.json`) |
| `answer.wav`, `answer2.wav`, … | **ваши** голосовые ответы (в репозиторий не попадают) |
| `requirements.txt` | список Python-библиотек |

## Требования

- **Windows 10 / 11** (используются Windows-специфичные вещи: loopback-захват звука, горячие клавиши, UI Automation).
- **Python 3.10 – 3.13** (при установке оставьте галочку на tcl/tk, он нужен для окна).
- **Zoom** (десктопное приложение), в котором вы **вошли в свой аккаунт**: бот заходит на пары под ним.
- **VB-Cable** (виртуальный аудиокабель), см. ниже.
- Интернет только для первого запуска (скачивается модель распознавания, ≈0,5 ГБ для `small`).

## Установка

### 1. Скачайте проект и поставьте библиотеки

```bash
git clone https://github.com/<ваш-ник>/<репозиторий>.git
cd <репозиторий>

python -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
```

Если работаете в PyCharm: откройте папку проекта, создайте интерпретатор `.venv` и выполните последнюю команду в терминале PyCharm.

### 2. Установите виртуальный микрофон VB-Cable (обязательно)

Бот «говорит» в Zoom через виртуальный аудиокабель: он проигрывает ваш файл в «вход» кабеля (`CABLE Input`), а Zoom слушает «выход» кабеля (`CABLE Output`) как обычный микрофон.

1. Скачайте **VB-CABLE Virtual Audio Device** с официального сайта: **https://vb-audio.com/Cable/**
   (программа бесплатная, на сайте есть кнопка пожертвования, платить не обязательно).
2. Распакуйте архив, запустите `VBCABLE_Setup_x64.exe` **от имени администратора** (ПКМ → «Запуск от имени администратора») и нажмите *Install Driver*.
3. **Перезагрузите компьютер.**
4. После этого в звуковых настройках Windows появятся устройства `CABLE Input` (воспроизведение) и `CABLE Output` (запись).

### 3. Настройте Zoom

Откройте Zoom → ⚙ Настройки:

**Аудио**
- **Микрофон:** `CABLE Output (VB-Audio Virtual Cable)`.
- **Динамик:** ваши реальные колонки/наушники. **Не** `CABLE Input`!
- **Подавление фонового шума:** `Низкое` или `Выкл.` (иначе Zoom может «съесть» запись).
- **Автоматически регулировать громкость микрофона:** выключить.
- **Автоматически подключаться к аудио с компьютера при входе:** включить.
- **Выключать микрофон при входе в конференцию:** включить (бот рассчитывает, что вы заходите с выключенным микрофоном).

**Видео**
- **Выключать моё видео при входе:** включить.
- **Всегда показывать диалог предпросмотра видео при входе:** выключить (так не нужно жать Join).

**Сочетания клавиш**
- «Включить/выключить звук» = `Alt+A` и галочка **Enable Global Shortcut** (иначе Alt+A не сработает, пока Zoom не в фокусе).

### 4. Звук Windows (один раз)

Панель управления → Звук → вкладка **Воспроизведение** → `CABLE Input` → Свойства → Дополнительно → **снимите** «Разрешить приложениям использовать устройство в монопольном режиме». То же самое для вкладки **Запись** → `CABLE Output`. Это лечит ошибку `0x8889000a` (устройство занято).

## Настройка под себя

Основные настройки находятся **в самом начале `zoom_attendance_bot.py`** (блок `SETTINGS`), каждая строка с комментарием.

### 1. Ваши голосовые ответы

Запишите себя (например, «Здесь» или «Present») и положите файлы рядом со скриптами:

```
answer.wav
answer2.wav
answer3.wav
```

- Подойдут любые файлы, имя которых начинается с `answer`. Либо положите файлы в папку `answers/` (там имена любые).
- Формат любой: wav, ogg/opus (голосовое из Telegram), mp3, m4a, flac. Тип определяется по содержимому, а не по расширению.
- При загрузке бот сам обрезает тишину в начале и конце и выравнивает громкость.
- Если файлов несколько, при каждой перекличке выбирается **случайный**, но не тот же, что в прошлый раз (`AVOID_REPEAT = True`).
- Записывайте коротко (1–2 секунды): чем короче, тем быстрее ответ.

### 2. Ваша фамилия и имя

В `zoom_attendance_bot.py` замените:

```python
TRIGGERS = [
    "ivan petrenko", "петренко", "петренка", "petrenko",
]
HOTWORDS = "Петренко Петренка Petrenko Иван Ivan"
```

- `TRIGGERS`: слова и фразы, на которые бот отвечает. Можно писать и кириллицей, и латиницей, добавьте падежи («Іванов, Іванова, Іванову»). Сравнение **нечёткое** и сводит кириллицу к латинице, поэтому `сальныков` / `сальніков` / `salnikov` считаются одним словом, перечислять каждую опечатку не нужно.
- `HOTWORDS`: подсказка модели распознавания, какие слова ожидать (сильно повышает точность на редких фамилиях).
- `MATCH_THRESHOLD` (по умолчанию 82): чем ниже, тем больше ловит, но тем чаще ложные срабатывания на похожие фамилии.

### 3. Язык пар

```python
LANGUAGE = "uk"   # "uk" украинский, "ru" русский, None = автоопределение
```

Язык сильно влияет на точность. Автоопределение на коротких кусках работает хуже.

### 4. Расписание

Скопируйте пример и отредактируйте:

```bash
copy schedule.example.json schedule.json
```

Формат `schedule.json`:

```json
{
  "join_minutes_before": 1,
  "week1_monday": "2026-10-26",
  "lessons": [
    {
      "week": 1,
      "days": ["mon", "wed"],
      "start": "08:30",
      "end": "10:00",
      "title": "Math. Lecture",
      "link": "https://us04web.zoom.us/j/1234567890?pwd=XXXXXXXX"
    }
  ]
}
```

| Поле | Значение |
|---|---|
| `week1_monday` | любой понедельник, который у вас является **1-й неделей**. Дальше недели чередуются 1, 2, 1, 2… |
| `join_minutes_before` | за сколько минут до начала заходить |
| `week` | `1` или `2`. **Если поле не указано, пара идёт каждую неделю.** Если у вас нет чередования, просто не пишите `week` |
| `days` | дни: `mon tue wed thu fri sat sun` |
| `start`, `end` | время `ЧЧ:ММ` (24 часа), по часам компьютера |
| `link` | ссылка на Zoom вида `https://….zoom.us/j/<id>?pwd=…` (пароль уже внутри ссылки) |
| `title` | название (показывается в логе) |
| `enabled` | необязательно; `false` = пропускать эту пару |

Пары без Zoom-ссылки (Google Doc, Telegram и т. п.) в расписание не добавляйте: боту там нечего открывать.

Проверить, что бот правильно понял неделю и пары:

```bash
python zoom_attendance_bot.py --today
```

### 5. Устройства звука

```python
VIRTUAL_MIC_PLAYBACK = "CABLE Input"   # куда играть ответ (часть названия устройства)
LOOPBACK_SPEAKER = None                # что слушать: None = устройство вывода Windows по умолчанию
```

Бот слушает **устройство вывода по умолчанию**. Если Zoom играет звук в другие наушники, впишите часть их названия в `LOOPBACK_SPEAKER`. Список устройств:

```bash
python zoom_attendance_bot.py --list-audio
```

### 6. Точность и нагрузка на ПК

```python
MODEL_SIZE = "small"     # tiny / base / small / medium / large-v3-turbo
DEVICE = "cpu"           # "cuda" для видеокарты NVIDIA (нужны библиотеки CUDA)
COMPUTE_TYPE = "int8"    # cpu: "int8", cuda: "float16"
CPU_THREADS = None       # None = авто (около половины ядер, максимум 4)
LISTEN_LIMIT_MIN = None  # например 20 = слушать только первые 20 минут пары
```

- Слабый ПК: `MODEL_SIZE = "base"` или `"tiny"`.
- Перекличка обычно в начале пары: `LISTEN_LIMIT_MIN = 20` сильно снижает нагрузку.
- Хотите максимум точности и есть NVIDIA: `DEVICE = "cuda"`, `COMPUTE_TYPE = "float16"`, `MODEL_SIZE = "medium"` или `"large-v3-turbo"`.

### 7. Остальные параметры

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `ZOOM_MUTE_HOTKEY` | `"alt+a"` | горячая клавиша Zoom «вкл/выкл микрофон» |
| `PAUSE_HOTKEY` | `"ctrl+alt+p"` | пауза/продолжение ответов |
| `STOP_AFTER_ANSWER` | `True` | после первого ответа не слушать до конца пары |
| `COOLDOWN_SEC` | `60` | пауза между ответами |
| `KILL_ZOOM_AT_END` | `True` | закрывать Zoom в конце пары |
| `OPEN_LINK_DIRECTLY` | `False` | `False`: ссылка открывается прямо в приложении Zoom; `True`: обычная ссылка в браузере |
| `AVOID_REPEAT` | `True` | не выбирать один и тот же ответ дважды подряд |
| `TRIM_AND_NORMALIZE` | `True` | обрезать тишину и выровнять громкость ответов |
| `PRE_UNMUTE_DELAY` | `0.35` | пауза после включения микрофона перед ответом |
| `LOW_PRIORITY` | `True` | работать с пониженным приоритетом, чтобы ПК не тормозил |

## Запуск

### Окно управления (удобный вариант)

Один раз создайте ярлык на рабочем столе (из `.venv`):

```bash
python create_desktop_shortcut.py
```

Дальше открываете ярлык **Zoom Bot**:

| Кнопка | Что делает |
|---|---|
| **Start** | запускает бота: он ждёт пары по расписанию, заходит и отвечает на перекличку |
| **Stop** | останавливает только бота, Zoom остаётся открытым |
| **Shutdown** | останавливает бота **и полностью закрывает Zoom** |
| **Today's classes** | показывает в логе неделю и пары на сегодня/завтра |
| 🗑 | очищает лог |

Подсказка о каждой кнопке появляется при наведении курсора.

### Из консоли

```bash
python zoom_attendance_bot.py                                # по расписанию
python zoom_attendance_bot.py --today                        # какая неделя и пары на сегодня/завтра
python zoom_attendance_bot.py --test-listen                  # только слушать и печатать, не отвечать
python zoom_attendance_bot.py --test-answer                  # через 5 с: unmute → ответ → mute
python zoom_attendance_bot.py --list-audio                   # список аудиоустройств и найденных answer-файлов
python zoom_attendance_bot.py --join "ССЫЛКА" --until 10:30  # зайти сейчас и слушать до 10:30
python test_join.py                                          # зайти на первую ссылку из расписания (или на ссылку-аргумент)
python test_join.py --join-only                              # только зайти и нажать Join
```

Горячие клавиши в тестовом режиме: `Ctrl+Alt+P` пауза, `Ctrl+Alt+T` ручной тест ответа.

`test_join.py` в отличие от основного бота **не останавливает прослушивание после первого ответа** и отвечает каждый раз, когда называют вашу фамилию (пауза между ответами `COOLDOWN_SEC = 20` секунд; поведение переключается через `UNLIMITED_ANSWERS` в начале файла).

## Проверка перед первой парой

1. `python zoom_attendance_bot.py --list-audio`: видны ли `CABLE Input` и ваши ответы.
2. Запустите свою тестовую встречу Zoom и выполните `python zoom_attendance_bot.py --test-answer`. Микрофон должен включиться, прозвучит запись и микрофон выключится.
3. Включите видео/голосовое, где произносят вашу фамилию, и запустите `--test-listen`. В логе должна появиться строка `<<< MATCH`.
4. `python test_join.py`: проверка входа, распознавания и ответа на реальной ссылке.
5. Рабочий запуск: окно **Zoom Bot** → Start.

Во время работы ПК должен быть **включён, не засыпать и не блокироваться** (иначе не сработают нажатие Join и Alt+A): отключите «Сон» и блокировку экрана по таймеру.

## Частые проблемы

| Симптом | Что делать |
|---|---|
| Ошибка `0x8889000a` при ответе | устройство занято: снимите «монопольный режим» у `CABLE Input` / `CABLE Output` (пункт 4 установки) и убедитесь, что **динамик** в Zoom не `CABLE Input` |
| В логе `[hint] no sound captured…` | бот слушает не то устройство: впишите нужное в `LOOPBACK_SPEAKER` (`--list-audio`) |
| Микрофон включается, но вас не слышно | в Zoom микрофон должен быть `CABLE Output`; шумоподавление `Низкое/Выкл.`; проверьте `--test-answer` |
| Микрофон включается/выключается «наоборот» | в Zoom включите «Выключать микрофон при входе» |
| Alt+A не срабатывает | в Zoom включите **Enable Global Shortcut** для «Включить/выключить звук» |
| Join не нажимается | выключите «диалог предпросмотра видео» в Zoom; либо сделайте скриншот кнопки Join и сохраните как `join_button.png` рядом со скриптами |
| Бот не слышит вашу фамилию | проверьте `LANGUAGE`, добавьте формы фамилии в `TRIGGERS`/`HOTWORDS`, попробуйте модель побольше |
| ПК тормозит | `MODEL_SIZE = "base"`, `LISTEN_LIMIT_MIN = 20`, уменьшите `CPU_THREADS` |
| Не та неделя | поправьте `week1_monday` и проверьте `--today` |
| Ошибка про `fromstring` | `python -m pip install "numpy<2"` |
| Предупреждение `data discontinuity in recording` | безобидно, бот его скрывает |

## Ограничения

- Только Windows.
- Бот реагирует на **упоминание фамилии**, а не понимает вопросы: если преподаватель задаст дополнительный вопрос, ответить он не сможет. Если фамилию просто упомянут в разговоре, он тоже ответит.
- Качество зависит от модели, языка и качества звука пары.
